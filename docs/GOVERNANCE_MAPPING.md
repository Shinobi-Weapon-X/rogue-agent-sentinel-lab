# Governance mapping — selected public frameworks

**Status:** Educational interpretation, not a compliance statement or normative regulatory mapping.

| Reference | Relevant principle | Lab demonstration | Gap |
| --- | --- | --- | --- |
| IMDA Model AI Governance Framework for Agentic AI | Bound agent authority | Three fictional agents with approved tool scopes | No enterprise identity governance |
| IMDA Agentic AI Framework | Human accountability | Human decision form, hold checkpoint | No verified release or approval authority |
| MAS AI Risk Management Guidelines | Risk oversight and lifecycle controls | Illustrative inventory, test report, risk register | No institutional risk committee or production model lifecycle |
| OWASP Agentic Top 10 | Tool misuse, goal hijack, delegation, rogue agents | Fictional detection scenarios and policy denials | No real threat emulation, LLM defence or penetration testing |
| NIST AI Agent Standards Initiative | Secure interoperable agents | Highlights the need for agent identity and permissions | No actual interoperability testing |

**Source links**

- IMDA: https://www.imda.gov.sg/About-IMDA/Emerging-Technologies-and-Research/Artificial-Intelligence
- MAS: https://www.mas.gov.sg/regulation/guidelines/guidelines-on-artificial-intelligence-risk-management-for-financial-institutions

- NIST: https://www.nist.gov/news-events/news/2026/02/announcing-ai-agent-standards-initiative-interoperable-and-secure
